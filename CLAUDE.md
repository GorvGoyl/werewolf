# Werewolf GM

Phone-first game master companion for Werewolf (Vite + React + Tailwind, no backend: the game and player names live in the phone's localStorage; an offline service worker in `public/sw.js` makes it installable). Every push to `main` deploys to https://werewolf.gourav.io (Vercel project `werewolf`, team `gorv`; gorv-werewolf.vercel.app forwards there); use pnpm.
