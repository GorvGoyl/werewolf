# Werewolf GM

A phone-first game master companion for Werewolf: it reads you the night script, tracks every role, works out who dies, runs the day vote with a timer, and ends with a full recap. Everything stays on the phone (localStorage), including the player names.

Roles: Wolves, Queen Wolf, Baby Wolf, Courtesan, Wizard, Seer and Villagers. Role names can be renamed to match your cards.

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm test       # game rules
pnpm build
```
